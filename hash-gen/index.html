NEDİR?
Bu panel, dosyaların dijital parmak izlerini (hash) çıkaran ve adli bilişim (forensics) ön analizi yapan bir sistemdir.

GÜVENLİK VE GİZLİLİK:
Sistemimiz %100 güvenlidir. Seçtiğiniz hiçbir dosya sunucularımıza yüklenmez. Tüm hesaplamalar tarayıcınızın belleğinde, tamamen sizin cihazınızda gerçekleşir. Hiçbir kayıt (log) tutulmaz.

TEKNİK DETAYLAR:
Bilgiler, JavaScript'in FileReader API'si ve CryptoJS kütüphanesi kullanılarak alınır. Magic Bytes analizi ile dosyanın gerçek türü, ilk 8 byte'lık "hex" imzası okunarak saniyeler içinde belirlenir.
WHAT IS THIS?
This panel is a forensic pre-analysis system that extracts digital fingerprints (hashes) of files.

SECURITY & PRIVACY:
Our system is 100% secure. No files are uploaded to our servers. All calculations occur locally within your browser's memory. Zero logs are kept.

TECHNICAL DETAILS:
Data is processed using JavaScript's FileReader API and the CryptoJS library. The real file type is determined via Magic Bytes analysis by reading the first 8 bytes of the "hex" signature.
